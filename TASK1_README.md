# Задача 1 — Телефонный справочник (C++ без Qt)

**Студент:** Chiwanza Mpundu Nankamba

Программа использует ООП, хранит контакты в файле `data/contacts.txt`, поддерживает добавление, удаление, редактирование, поиск и сортировку. Проверка вводимых данных реализована с помощью регулярных выражений и проверки календарной даты.

## Структура

- `include/PhoneNumber.h`, `src/PhoneNumber.cpp` — телефон и тип номера.
- `include/Contact.h`, `src/Contact.cpp` — данные одного контакта.
- `include/ContactValidator.h`, `src/ContactValidator.cpp` — проверка имени, email, телефона, даты.
- `include/ContactManager.h`, `src/ContactManager.cpp` — управление коллекцией контактов.
- `include/IContactStorage.h` — интерфейс хранения данных для последующего расширения.
- `include/FileStorage.h`, `src/FileStorage.cpp` — сохранение и загрузка из файла.
- `include/ConsoleUI.h`, `src/ConsoleUI.cpp` — консольное меню и ввод пользователя.
- `src/main.cpp` — точка входа и выбор способа хранения.

## Сборка в Windows / VS Code

Из корня репозитория в терминале PowerShell:

```powershell
.\build.bat
.\phonebook.exe
```

Компилятор: g++ с поддержкой стандарта C++17 (в том числе TDM-GCC 10.3.0).

Данные сохраняются автоматически после изменения и при выходе. Перед сборкой и запуском нужно перейти в корень проекта.

## Примечания

- Графический интерфейс Qt и PostgreSQL добавляются в Задаче 2, не здесь.
- Дата рождения вводится в формате `YYYY-MM-DD`.
- Для каждого контакта обязателен хотя бы один телефонный номер.
- Валидация имён поддерживает латиницу и кириллицу.
- Для удаления контакта требуется подтверждение `y`.
