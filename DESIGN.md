# Задача 0. Проектирование структуры приложения «Телефонный справочник»

**Цель:** Разработать структуру приложения для хранения и управления контактами с использованием C++ и Qt.

### Основные классы

1. **Contact** — хранит информацию об одном контакте: имя, фамилию, отчество, адрес, дату рождения, email и телефонные номера.

2. **PhoneNumber** — хранит номер телефона и его тип (домашний, рабочий, служебный).

3. **ContactManager** — управляет контактами: добавление, удаление, редактирование, поиск и сортировка.

4. **ContactValidator** — проверяет корректность имени, фамилии, email, телефонных номеров и даты рождения.

5. **IContactStorage** — определяет общий интерфейс для сохранения и загрузки контактов.

6. **FileStorage** — реализует сохранение и загрузку контактов из файла.

7. **DatabaseStorage** — реализует сохранение и загрузку контактов из базы данных PostgreSQL.

8. **MainWindow** — реализует графический интерфейс приложения с использованием Qt.

### Взаимодействие классов

Класс Contact содержит коллекцию объектов PhoneNumber с использованием std::vector.

ContactManager управляет контактами и использует ContactValidator для проверки данных.

Сохранение и загрузка контактов выполняются через интерфейс IContactStorage. Классы FileStorage и DatabaseStorage реализуют этот интерфейс.

Выбор способа хранения данных выполняется в функции main().

### Этапы реализации

- **Задача 1:** Консольное приложение C++ с хранением контактов в файле.
- **Задача 2:** Добавление графического интерфейса Qt и поддержки PostgreSQL с сохранением возможности хранения в файле.
