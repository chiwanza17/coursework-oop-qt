# Курсовая работа по ООП

**Тема:** Разработка приложения «Телефонный справочник»

**Студент:** чиванза мпунду нанкамба

**Язык программирования:** C++

**Графический фреймворк:** Qt

**База данных:** PostgreSQL

## Описание проекта

Разработка телефонного справочника для хранения и управления контактами.

Приложение позволяет добавлять, удалять, редактировать, искать и сортировать контакты.

## Этапы разработки

- **Задача 0:** Проектирование структуры приложения и классов.
- **Задача 1:** Разработка консольного приложения C++ с хранением данных в файле.
- **Задача 2:** Добавление графического интерфейса Qt и базы данных PostgreSQL.
